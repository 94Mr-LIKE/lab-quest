# 實驗闖關（lab-quest）

給國小到高中學生玩的自然科「實驗闖關」網頁遊戲，手機、平板都能玩。生物、物理、化學、地科四科都有，像 Candy Crush 一樣在關卡地圖上一關接一關往上走。

每一關是一個實驗：把道具拖到實驗桌、用拉桿調數值、近看讀刻度，達成目標就過關。
- 不用計算，也沒有選擇題。
- 道具裡有陷阱，挑錯了會看到後果。
- 做出危險動作時「老師喊停」，不演爆炸。

## 目前狀態：企劃與原型階段

- `prototype/`：同一關的三種畫面原型。從國二的 50 關地圖進入，第 19 關「水在幾度沸騰？」可以從頭玩到過關。
- 正式版開發中：國小、國一、國二、國三各 50 關，高中基礎、高中選修各 100 關。

## 本機開啟

- 2D 版本（`prototype/v1-clean`、`prototype/v3-game`）：直接雙擊 `map.html` 就能開。
- 3D 版本（`prototype/v2-3d`）：瀏覽器不允許用 file:// 載入程式模組，所以要先開本機伺服器：

```
python -m http.server 8000
```

再用瀏覽器開 <http://127.0.0.1:8000/prototype/>。

## 隱私與安全

- 純靜態網站：不需要伺服器、不登入、不收集任何個人資料、沒有廣告和追蹤。
- 遊戲裡的實驗是模擬操作。真的要做實驗時，一定要在學校實驗室、有老師在旁邊。
- 緊急狀況請撥 119；誤食或接觸化學品，可以諮詢臺北榮總毒藥物防治諮詢中心 02-2871-7121。
