# 瘋狂實驗室（lab-quest）

給國小到高中學生玩的自然科實驗解謎網頁遊戲，手機、平板都能玩。生物、物理、化學、地科四科都有，像 Candy Crush 一樣在關卡地圖上一關接一關往上走。

每一關是一個任務，像密室逃脫的解謎關：
- 任務目標一句話講清楚，例如「讓鋼珠掉進 105 cm 外的杯子」「配出 100 mL、2.0 M 的鹽酸」。
- 器材和藥品自己挑，裡面有陷阱；數量、位置、高度、順序自己決定。
- 遊戲用玩家的數據算出結果（落點幾 cm、濃度幾 M），達成目標就過關。
- 做出危險動作（例如把水加進濃酸）會直接失敗，看到原因後重來；不演爆炸、受傷。
- 沒有選擇題。

## 目前狀態：企劃與原型階段

- `prototype/`：原型試玩首頁。
  - `prototype/missions/`：新玩法「任務目標制」。任務 A 把鋼珠送進杯子（國二物理，可以調放球高度、斜坡彎曲程度、桌高）、任務 B 配出 2.0 M 鹽酸（高中化學）。配色用 P7 科學海報。
  - `prototype/cover/`：封面（選定第 1 個方向；`?v=2`、`?v=3` 是沒選上的參考），可以播主題曲。
  - `prototype/sfx.html`：音效試聽。音效檔在 `prototype/sfx/`，遊戲裡用喇叭按鈕開關。
  - `prototype/v1-clean`、`v2-3d`、`v3-game`：舊玩法的三種畫面（國二 50 關地圖、第 19 關）。
  - `prototype/records.html`：我的紀錄（過關數、星星、學到的安全守則、存檔碼），只存在玩家自己的裝置。
- 正式版開發中：國小、國一、國二、國三各 50 關，高中基礎、高中選修各 100 關。
- 首頁的遊玩人數計數器：程式已寫好，等計數端點建好後才會打開；只送一次匿名的「+1」，不送任何個人資料。

## 本機開啟

- 2D 頁面（任務、封面、`v1-clean`、`v3-game`）：直接雙擊 html 就能開。
- 3D 版本（`prototype/v2-3d`）：瀏覽器不允許用 file:// 載入程式模組，所以要先開本機伺服器：

```
python -m http.server 8000
```

再用瀏覽器開 <http://127.0.0.1:8000/prototype/>。

## 隱私與安全

- 純靜態網站：不需要伺服器、不登入、不收集任何個人資料、沒有廣告和追蹤。
- 遊戲裡的實驗是模擬操作。真的要做實驗時，一定要在學校實驗室、有老師在旁邊。
- 緊急狀況請撥 119；誤食或接觸化學品，可以諮詢臺北榮總毒藥物防治諮詢中心 02-2871-7121。

## 素材與第三方程式

- Three.js r186（MIT 授權）：只有 3D 版本使用，授權全文在 `prototype/v2-3d/lib/LICENSE`。
